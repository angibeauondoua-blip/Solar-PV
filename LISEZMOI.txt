SOLAR PV - Application Android

Fonctionnalités :
- Calcul estimatif des besoins énergétiques, panneaux, batteries, onduleur et MPPT.
- Appareils prédéfinis et ajout/suppression libre.
- Enregistrement et restauration locale du projet (dans le navigateur/appareil).
- Copie des résultats, thème clair/sombre selon le système.

Pour compiler un APK :
1. Installer Android Studio (version récente) et le SDK Android.
2. Ouvrir le dossier SolarPV dans Android Studio.
3. Laisser Gradle synchroniser le projet.
4. Menu Build > Build Bundle(s) / APK(s) > Build APK(s).
5. Le fichier APK se trouvera dans app/build/outputs/apk/debug/ (pour la version debug).

Les résultats sont des estimations de pré-dimensionnement et doivent être validés avant installation.
